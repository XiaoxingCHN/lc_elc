# 任务：修复制袋贴标“选择器件无反应”（客户端 1.3.2+10，Windows / Android）

- Status: done（产物已构建、登记；签名清单与更新通道待提交后处理）
- 目标/用户场景：用户在“制袋贴标”表单输入 `STM32F401CCU` 后点选建议或直接生成袋码，界面没有任何“已选中”的反馈，提交时仍提示“请选择器件…”（截图 2026-11-10）。要求先调试清楚再交付可安装包。
- 当前问题及复现方法：
  - 选中建议走 `_run()`，而 `_run()` 在 `_busy` 为真时**静默 return**；搜索/队列刷新期间的点击等于没发生。
  - `_selectSuggestion` 先 `await _api.detail()` 才 `setState`，档案读取慢时界面毫无变化；读取抛错时建议被**整条丢弃**（旧代码 `catch { rethrow; }`）。
  - 建议面板被外部点击/失焦关闭后输入框仍有文字，再次点输入框不会重新搜索，看起来“点了没反应”。
  - 选中后 `_releaseSuggestion` 用 `item_key` 比对，而详情可能把 `lcsc:C…` 换成 `lab:…`；键不同则不清除，改词后仍保留旧选中，可能给旧器件制袋。
- 验收标准：选中当帧显示“已选：<名称>”和“已选中，正在读取内部档案…”，档案读完后 Create 可用；档案失败仍保留选中并给出中文提示；关掉面板后再次点输入框会重新搜索；选中后改词必须清除选中；`flutter analyze` 0 error / 0 warning；`flutter test` 全绿。
