# 任务：Android已授权安装仍失败

- 复现：用户已允许安装未知应用，1.1.1+4下载通道1.1.2+5后仍显示通用“安装未开始”提示。
- 范围：客户端Android安装缓存校验、安装器状态/错误反馈、相关共享界面和回归测试；新版本1.1.3+6，不覆盖已发布build5；发布授权沿用本轮明确请求。
- 可确认缺陷：旧代码要求absolutePath==canonicalPath，会拒绝指向合法私有缓存的系统别名；与canonical缓存根比较才是正确边界。手机当前具体失败阶段尚无日志，不能将推断当实机确诊。
- 验收：合法别名路径通过，越界/逃逸/长度/hash错误拒绝；安装权限、身份、系统安装器及取消显示具体信息；构建/签名核验；原生实际安装仍需用户验证。
- 安全：仅自己的私有缓存与现有签名包；不得通过放宽目录或APK身份校验来绕过错误。不使用模拟器冒充实体设备验收。
- 测试/产物/发布/交接：完成后补齐；旧应用的安装缺陷不能靠下载新APK修改正在运行的原生代码，必要时手动覆盖一次引导。
