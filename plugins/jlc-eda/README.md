# 实验室库存联动（嘉立创 EDA 专业版 × Odoo 19）

本机发行包 **4.2.0**，扩展 UUID 沿用旧版 `1329a87d576b4b8cbb8592b1c1012b8b`，可在扩展管理器中按同一扩展升级。

**定位：画图助手，不是第二个库存系统。** 插件只在画原理图/PCB 时提供三件事：这个器件有没有库存、有的话在哪个库位和袋、整张 BOM 一键出库。入库、归还、扫码追溯和单件领用在网页端与 Flutter 客户端办理。

## 4.2.0 变更

- 出库结果未知时，面板保留原请求并阻止新出库。浏览器模拟宿主已验证重扫后同键重试，真实宿主安装、重开恢复和实际领用仍待验收。
- 主按钮改用成对的底色与文字色（深色 `#C9FF3F`/`#0A0D06`，浅色 `#3D7A00`/`#FFFFFF`），修复深色下白字最低约 1.83:1 的问题。
- 连接入口统一为「连接设置」，去掉与页签重复的头部按钮；未连接与网络提示不再提旧版本机桥接。
- BOM 的「需求/可用/缺口」列不再逐字换行；信息性小字统一到 12 px；确认弹窗限制 Tab 焦点并恢复原焦点。

## 4.1.4 变更

- 替代料查询会保留原理图中的值与封装，即使同编号的首个位号缺少封装。
- 候选按实验室 SN 显示，并列出可用量、库位和袋。可展开并手动勾选。
- 长位号会换行。查询完成后，缺少匹配结果的行会给出提示。

## 4.1.2 变更（相对 4.1.1）

- **修复：插件转发层再次丢掉 name/footprint**。4.1.1 只修了服务端，插件 `api.js` 的 `equivalents()` 仍只发 item_key+quantity，导致所有未采集编号返回空候选
- **修复：`lab_eda` 缺 `LabApiError` import**。「库存未知」的真正来源——`/catalog/detail` 对未采集编号抛 NameError，插件映射成 UNKNOWN 而非 NOT_FOUND
- **连接器补 `lab_mpn` 搜索**：`WAFER-GH1.25-2PLB` 这类只有型号的器件，以前只搜规格文本，永远 0 候选

## 4.1.1 变更（相对 4.1.0）

- **修复：库存未知的行不请求等效件**。以前只有「缺料」和「资料库无此编号」两类会去实验室库存找候选，「库存未知」（编号未采集）被漏掉——这正是「明明有 100nF 却不匹配」的原因
- **修复：groupBom 丢掉了封装**。即使请求里带了值，服务端也拿不到封装，只能按值模糊匹配

## 4.1.0 变更（相对 4.0.0）

- **无 C 编号器件并入主表**：不再单独一栏，状态标「无 C 编号」，库位列直接显示可勾选的实验室库存候选
- **未采集的 C 编号也能找等效件**：`C51376376` 这种资料库没有的编号，按「值 + 封装」去实验室库存找候选（标「依据较弱」）
- **表格滚动修复**：内容超出时能一直滚到底
- **资料库缺编号时给出可操作提示**：「资料库无此编号，需抓取或建档」，不再笼统说「库存未知」

## 4.0.0：不再需要安装任何额外程序

移除了本机桥接（Node 进程 + 配对码 + 89 MB 运行时），插件改为用 **EDA 密钥**直连服务器。包体积 **89 MB → 103 KB**。

- 密钥由库存管理员在网页端「管理 → EDA 插件密钥」发放，**绑定到具体账号**——插件里做的每一次出库，操作人都是密钥的主人。
- 离职或密钥外泄时，管理员点「吊销」即可立即失效，不影响其他人。
- 管理页能看到每把密钥的「最近使用时间」，异常使用可以发现。

扩展通过 `Authorization: bearer` 将密钥发送到项目的 `lab_eda` 接口。该模块校验独立签发的 EDA 密钥，并以绑定用户执行库存业务。

## 1. 功能

保留四个页签：

- **器件库**：按 C 编号 / 名称 / 型号 / 参数检索，看实时库存与库位。
- **原理图库存**：读取选中器件、当前图页或整张工程 BOM，对比实验室库存；缺料行可展开**等效候选**（同规格不同 C 编号），勾选后才进入出库。
- **连接设置**：服务器地址与 EDA 密钥。
- **诊断**：脱敏后的日志与环境信息。

## 2. 安装

1. EDA 专业版 → 设置 → 扩展 → 导入扩展，选择 `lab-inventory-odoo_v4.2.0.eext`。
2. 启用扩展，并开启「**外部交互**」权限（没有它任何网络请求都会失败）。
3. 顶部菜单出现「库存联动」。

## 3. 获取并填写密钥

1. 打开 `https://team.l-creation.club/team/lab/settings` 的「管理」页（需要库存管理员权限）。
2. 在「EDA 插件密钥」区块选择目标账号，填备注与有效期（默认 365 天，0 表示永不过期），点「发放」。
3. 复制显示的密钥（形如 `eda_xxxxxxxx`）。**它只显示这一次**，关闭后只能吊销重发。
4. 打开插件「连接设置」，服务器地址保持默认，粘贴密钥，点「保存并连接」。

连接成功后「当前会话」会显示密钥绑定的账号名。

## 4. 安全边界

- **密钥明文保存在本机 EDA 配置里**。EDA 扩展拿不到 Windows DPAPI，这一点绕不过去——与浏览器保存密码同一水位。
- 其他能读取 EDA 配置的本机程序可能取得该密钥。管理员可在离职或泄露时吊销。
- 密钥绑定到具体账号，出库记录里的「操作人」就是密钥主人；离职时管理员吊销即可。

## 5. 出库与权限

- 普通操作员只能给自己领料；管理员可以代他人领料。
- 权限完全由 Odoo 服务端判定，插件不能越权。
- 一键出库必须先预览再确认，只有确认后才写入 Odoo；结果严格四态（成功 / 需重新预览 / 未知 / 失败）。
- 领用备注会写明等效替代关系（如 `C14663 → C1525 替代`）。

## 7. 目录

- `src/main/`：扩展主模块（配置、Odoo 客户端、面板桥接）
- `src/iframe/`：面板界面
- `src/shared/`：BOM 解析、等效件、出库四态等纯逻辑
- `src/tests/`：单元测试与打包测试
- `scripts/`：构建与校验

构建可用 `npm run build`。单元和包测试使用 `npm run test:all`，成品核验使用 `npm run verify`。实装版通过 EDA 扩展管理器导入，与 Flutter 应用内更新通道独立。
